## 🛠️ توليد اللقطات والرسم المميز

```bash
pip3 install pillow arabic-reshaper python-bidi
cd store_assets/play_store_assets

# 1) ضع اللقطات الخام (1080×1920) في screenshots/raw/ar/
#    أسماء الملفات يجب أن تحوي أحد المفاتيح:
#    cycles / record / prices / tools / vaccination / diseases / articles / notes
python3 make_screenshots.py        # → screenshots/phone/ar/

# 2) الرسم المميز
python3 make_feature_graphic.py    # → feature_graphic/ar/
```

## 📝 نصوص بطاقة المتجر (عربي — ar)

**اسم التطبيق (≤30):**
```
فرخة لإدارة مزارع الدواجن
```

**الوصف المختصر (≤80):**
```
أدِر دورات التسمين، تابع الأسعار والتحصينات، واحسب FCR وكل أرقام مزرعتك بسهولة
```

**الوصف الكامل (≤4000):**
```
فرخة — تطبيقك المتكامل لإدارة مزرعة الدواجن من أول يوم في الدورة حتى البيع.

صُمّم فرخة لمربّي الدواجن وأصحاب مزارع التسمين ليجمع كل ما تحتاجه لمتابعة مزرعتك في مكان واحد، وبواجهة عربية بسيطة.

أبرز المزايا:

• إدارة الدورات
أنشئ دورة لكل عنبر وتابعها يومياً: أعداد الطيور، الوزن، استهلاك العلف، النفوق، والأدوية والتحصينات.

• المؤشّرات والتقارير
احسب معامل التحويل الغذائي (FCR)، متوسط النمو اليومي، نسبة النفوق، والتكاليف والأرباح — وصدّر تقاريرك بصيغة PDF و Excel.

• أسعار السوق
تابع أسعار الفراخ والأعلاف والبيض أولاً بأول.

• أدوات حسابية للدواجن
معامل التحويل الغذائي، الوزن حسب العمر، درجة الحرارة حسب العمر، كثافة الفراخ، دراسة الجدوى، تكلفة الإنتاج والعائد على الاستثمار، والمزيد.

• التحصينات والأمراض
جدول تحصينات حسب العمر، ودليل لتشخيص الأمراض الشائعة من الأعراض.

• مقالات ونصائح
محتوى إرشادي يساعدك على تحسين أداء مزرعتك.

• نوتة الملاحظات
دوّن ملاحظاتك وتذكيراتك بسرعة، محفوظة على جهازك.

• إشعارات فورية
تنبيهات بمواعيد التحصين والمهام المهمة في دورتك.

خصوصيتك وأمانك:
تُنقل بياناتك عبر اتصال مشفّر، ويمكنك طلب حذف حسابك وبياناتك في أي وقت.
```
